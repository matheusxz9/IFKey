# IFKEY - Sistema de Gerenciamento de Chaves das Salas de Aula (PROJETO INTEGRADOR I)

## O Que é o Sistema

O IFKEY é uma aplicação web desenvolvida para auxiliar no controle, organização e acompanhamento das chaves das salas de aula e laboratórios localizados no setor de apoio do IFRN Campus Currais Novos. 

## Problema

Foi observado que atualmente, o controle das chaves das salas e laboratórios presentes na sala do Apoio é realizado de forma manual, utilizando papel e caneta. O metodo presente tem dificultado o trabalho o trabalho dos responsaveis do setor nas atividades como: identificação de quem está utilizando uma determinada chave, quais chaves estão disponíveis e quais ambientes estão ocupados. Podendo ocasionar perda de informações, atrasos e dificuldades no controle e na localização das chaves.

## Objetivo  

O sistema tem por objetivo principal permitir a realizção do gerenciamento das chaves dos laboratórios e salas de maneira mais organizada e eficiente, possibilitando o registro de retiradas e devoluções, o acompanhamento da disponibilidade das chaves e a identificação dos responsáveis pela utilização.

## Tecnologias utilizadas

- React — desenvolvimento da interface do usuário (frontend).
- NestJS — desenvolvimento da API e das regras de negócio (backend).
- PostgreSQL — armazenamento e gerenciamento dos dados.
- Docker — criação e gerenciamento dos ambientes de execução da aplicação.
- Git — controle de versão do código-fonte.
- GitHub — hospedagem do código e colaboração entre os integrantes da equipe.
